## 这是什么？

中国税务居民每年需对**境外投资所得**（美股、港股、日股、基金收益等）进行个人所得税申报。**CRS（共同申报准则）** 下，税务机关可通过信息交换获取你的境外账户数据，未申报面临补税+滞纳金+罚款风险。

本指南专为**富途牛牛（Futu Securities）用户**设计，提供：

| 资源 | 说明 |
|------|------|
| 🧮 **FIFO 计算器** | 多年度、多文件导入，自动按先进先出计算成本，输出报税底稿 |
| 📖 **CRS 解释** | 什么是 CRS、谁受影响、信息交换后会发生什么 |
| 📐 **税法政策参考** | 分国不分项抵免法、税率、汇率规则、盈亏互抵规则 |
| 🖱️ **电子税务局填报指引** | 自然人电子税务局逐步操作截图与说明 |
| ❓ **常见问题 FAQ** | 14 个高频问题解答 |

## 我需要报税吗？

**简单判断（任一为"是"即需申报）：**

- ✅ 年境外收入（股息+利息+资本利得）合计 ≥ 中国个税起征点
- ✅ 收到银行/券商的 CRS 信息申报通知
- ✅ 在富途/耀才/辉立等香港券商有港美股账户
- ✅ 通过港股通、沪股通以外渠道投资境外市场（如美股、港股、日股）

> ⚠️ **亏损也要申报！** 资本利得亏损虽不抵税，但**不申报**属于瞒报，CRS 数据交换后会被发现。

**申报截止日期：每年 6 月 30 日**

## 功能亮点

### 🎯 专为富途用户设计

- 内置富途账户迁移处理（7362+6981→1318 内部迁移，非交易，不影响成本）
- 支持富途基金（880002、880054）收益计算
- H 股分红自动还原毛额（扣除 10% 预扣税后还原为税前金额）
- 支持富途日股（JPY）交易和股息预扣税抵免

### 📊 多年度 FIFO 计算

- 支持 2021-2026 多年度数据一次导入
- 跨年持仓成本自动结转
- 同国同年同税目盈亏互抵，跨税目/跨国/跨年不互抵（符合税法）

### 🌍 合规汇率处理

- 使用央行各月末中间价（不是固定汇率，符合合规申报要求）
- USD/CNY、HKD/CNY、JPY/CNY 分别处理
- 汇率数据可在「汇率」Tab 查看和编辑

### 📄 报税底稿导出

- 一键导出 Markdown 格式报税底稿
- 含逐笔明细，可逐项勾选核对
- 格式对齐自然人电子税务局申报字段

## 常见问题

### Q1：我境外投资亏了，还需要申报吗？

**需要。** 亏损不缴税，但**不申报**属于瞒报。CRS 信息交换后，税务机关可发现你名下有境外账户，如未申报会被要求说明。

### Q2：计算器的结果可以直接用来填报吗？

**建议核对后使用。** 计算器基于你上传的数据计算，请确认数据完整（含往年买入记录，否则 FIFO 成本不准）。导出底稿后，对照 `references/filing-guide.md` 逐步填报。

### Q3：富途的账户迁移（7362→1318）怎么处理？

账户内部迁移**不是交易**，不应产生盈亏。计算器已内置此逻辑，迁移记录会被自动识别并跳过。

### Q4：用哪天的汇率？

合规申报使用**央行各月末中间价**（PBOC month-end midpoint）。不要用固定汇率（如 7.2），也不要用交易当日汇率。计算器内置了 2021-2025 年月末汇率，可直接使用。

### Q5：我在多个券商有账户，可以用这个计算器吗？

计算器目前针对**富途牛牛数据格式**优化，内置美国、中国香港、日本三个来源地。其他券商（耀才、辉立等）的数据需手动整理为相同格式后上传，或等待后续版本支持。未识别市场会被提示并排除计算，避免误归类。
